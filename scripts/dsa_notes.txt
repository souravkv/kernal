1.1 Basic terms

    Data item / field: the smallest named unit. Example: Name .

1.2 What is a data structure?
A data structure is a way of storing and organising data in memory so that it can be used
efficiently. It has two parts:

1. Organisation: how items are arranged in memory.
2. Operations: what you can do (insert, delete, search, traverse, sort, merge).

Classification

                             DATA STRUCTURES
                         /                     \
               PRIMITIVE                      NON-PRIMITIVE
          (int, float, char, bool)            /           \
                                     LINEAR             NON-LINEAR
                               (Array, Linked List,      (Tree, Graph)
                                Stack, Queue)


    Linear: elements form a sequence; each has one predecessor and one successor.
    Non-linear: an element can connect to many others.
    Static vs dynamic: size fixed at compile time (arrays) versus growing and shrinking at
    run time (linked lists).


1.3 Abstract Data Type (ADT)
An ADT describes what a structure does (values and operations) without saying how it is
implemented. [AHU] defines an ADT as a mathematical model with a collection of
operations defined on it.


  ADT                Operations (the interface)               Possible implementations

  Stack              push, pop, peek, isEmpty                 array, linked list

  Queue              enqueue, dequeue, front                  circular array, linked list

  List               insert, delete, search                   array, linked list

  Dictionary         insert, delete, lookup                   hash table, BST


Analogy: a TV remote is an interface. You don't need to know the circuits inside.


1.4 What is an algorithm?
A finite sequence of well-defined steps that solves a problem. Five properties:

1. Input: zero or more.
2. Output: at least one.
3. Definiteness: each step is unambiguous.
4. Finiteness: it stops after finitely many steps.
5. Effectiveness: each step is simple enough to be carried out.


1.5 Writing algorithms the Lipschutz way
Algorithm 1.1: Find the largest element of an array DATA with N elements


 1. [Initialise]     Set MAX := DATA[1], K := 2.
 2. Repeat Steps 3 and 4 while K <= N:
 3.      If MAX < DATA[K], then: Set MAX := DATA[K].
 4.      Set K := K + 1.
 5. Write: MAX.
 6. Exit.


Python version:


 def find_max(data):
      mx = data[0]
      for x in data[1:]:
            if x > mx:
                mx = x
      return mx


Flowchart symbols (text form)


   ( Start/End )     [ Process ]    < Decision? >       /Input-Output/


Flowchart of Algorithm 1.1:


   (Start) → [MAX=DATA[1], K=2] → <K <= N?> ──No──→ /Print MAX/ → (End)
                                         │Yes
                                         ▼
                              <MAX < DATA[K]?> ─Yes→ [MAX=DATA[K]]
                                         │No                    │
                                         └────────┬─────────┘
                                                    ▼
                                                [K = K+1] ──→ (back to K <= N?)




1.6 Four stages of problem solving
1. Understand the problem: input, output, constraints.
2. Plan: pick a data structure and an algorithm.
3. Implement: write the code.
4. Review: test with normal, edge and large cases, and check the cost.


1.7 Operations on data structures
Traversing, searching, inserting, deleting, sorting, merging.


Common mistakes
    Confusing a data structure (the storage layout) with an algorithm (the procedure).
    Starting to code before understanding the input and output.
    Ignoring edge cases such as an empty array or a single element.


Quick revision
Data → record → file. A data structure is organisation plus operations. An ADT is a what-
only interface. An algorithm is finite and definite, with input and output.

Practice Set B — Coding Problems with Solutions

Code Problem 1 (Easy): Largest and smallest
Statement: Given an array, return its minimum and maximum in one pass.
Example: [4, 9, 1, 7] → (1, 9)
Solution:


 def min_max(a):
      mn = mx = a[0]
      for x in a[1:]:
            if x < mn: mn = x
            if x > mx: mx = x
      return mn, mx


Complexity: Time O(n), space O(1).


Code Problem 2 (Easy): Swap without a temporary variable
Statement: Swap two integers a and b without a third variable.
Example: a=5, b=9 → a=9, b=5
Solution:


 def swap(a, b):
      a = a + b         # a = 14
      b = a - b         # b = 5
      a = a - b         # a = 9
      return a, b


(In Python you can simply write a, b = b, a ; in C use the arithmetic or XOR trick.)
Complexity: O(1).


Code Problem 3 (Easy): Count vowels
Statement: Count the vowels in a string (case-insensitive).
Example: "Data Structures" → 5
Solution:

  def count_vowels(s):
      return sum(1 for ch in s.lower() if ch in "aeiou")


Complexity: O(n).


Code Problem 4 (Easy): Sum of digits (algorithm-writing practice)
Statement: Write a numbered-step algorithm (Lipschutz style) and code to find the sum of
digits of N.
Algorithm: 1. Set SUM := 0. 2. Repeat while N > 0: SUM := SUM + (N mod 10); N := N div 10.
3. Write SUM. 4. Exit.
Solution:


  def digit_sum(n):
      s = 0
      while n > 0:
            s += n % 10
            n //= 10
      return s


Example: 4521 → 12. Complexity: O(log₁₀ n).

2.1 Why analyse?
Running time depends on the machine, language and input, so we count basic operations
as a function of input size n. We ignore constants and keep the dominant term.


2.2 Time and space complexity
   Time complexity T(n): number of basic steps.
   Space complexity S(n): extra memory used besides the input.


2.3 Cases (Lipschutz: best, average, worst)
Example: linear search for ITEM in an array of n elements.


 Case                       Meaning                               Comparisons

 Best                       Item at position 1                    1

 Average                    Item uniformly anywhere               (n+1)/2

 Worst                      Last position or absent               n


We usually quote the worst case because it is a guarantee.


2.4 Asymptotic notation
   O(g(n)) is an upper bound: f(n) ≤ c·g(n) for n ≥ n₀.
   Ω(g(n)) is a lower bound.
   Θ(g(n)) is a tight bound (both O and Ω).

  cost
    │                                      c·g(n) ← upper bound
    │                                 ╱╱
    │                           ╱╱     ·    f(n)
    │                     ╱╱    ·
    │                ╱╱ ·
    │          ╱╱·
    │    ╱╱·     ← after n0, f(n) stays below c·g(n)
    └───────────┬──────────────────── n
                     n0


Rules
1. Drop constants: 5n → O(n).
2. Drop lower-order terms: n² + n + 7 → O(n²).
3. Sequential blocks add: O(n) + O(n²) → O(n²).
4. Nested loops multiply: n × n → O(n²).


2.5 Growth-rate ladder

 Slowest growth (best)                                       Fastest growth (worst)
 O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)


Operations needed (approximate):


  n                log₂ n        n log₂ n        n²            2ⁿ

  10               3             33              100           1,024

  100              7             664             10,000        1.3×10³⁰

  1,000            10            9,966           1,000,000     ∞ (practically)

2.6 Analysing code: worked examples

 # A: O(1)
 x = a[0]


 # B: O(n)
 for i in range(n):
        total += a[i]
 # C: O(n^2)     (nested)
 for i in range(n):
      for j in range(n):
          count += 1


 # D: O(n^2)     (inner depends on i: 0+1+...+(n-1) = n(n-1)/2)
 for i in range(n):
      for j in range(i):
          count += 1


 # E: O(log n)     (i doubles each time)
 i = 1
 while i < n:
      i *= 2


 # F: O(n log n)
 for i in range(n):             # n times
      j = 1
      while j < n:              # log n times
          j *= 2




2.7 Space complexity
   Sum of an array with one loop variable: O(1) extra space.
   Building a copy of the array: O(n) extra space.
   Recursion depth d uses O(d) stack space (more in Module 5).


2.8 Time–space trade-off
You can often be faster by using more memory. Example: precompute a lookup table to
answer queries in O(1), costing O(n) space.


Common mistakes
   Saying O(2n) is different from O(n). It is not.
   Treating best-case as the cost.
   Forgetting that a + b on huge numbers or strings may not be O(1).


Quick revision
Big-O means "no worse than". Drop constants and small terms. A loop that halves or
doubles gives log n. Nested loops multiply.

Practice Set B — Coding Problems with Solutions

Code Problem 1 (Easy): Count loop operations
Statement: Write a function that returns how many times the inner statement runs for for
i in range(n): for j in range(i, n): ... . Compare with the formula n(n+1)/2.
Solution:

 def count_ops(n):
      c = 0
      for i in range(n):
            for j in range(i, n):
                 c += 1
      return c


 print(count_ops(5), 5 * 6 // 2)          # 15 15


Complexity: O(n²) — matches n(n+1)/2.


Code Problem 2 (Easy): Duplicates, two ways
Statement: Check whether an array has a duplicate. Give an O(n²) and an O(n) (average)
solution.
Solution:


 def has_dup_slow(a):                      # O(n^2) time, O(1) space
      for i in range(len(a)):
            for j in range(i + 1, len(a)):
                 if a[i] == a[j]: return True
      return False


 def has_dup_fast(a):                      # O(n) time, O(n) space
      seen = set()
      for x in a:
            if x in seen: return True
            seen.add(x)
      return False


Note: this is the time–space trade-off.


Code Problem 3 (Easy): Sum 1..n three ways
Statement: Compute 1 + 2 + … + n by (a) a loop, (b) the formula, (c) recursion. State each
complexity.
Solution:


 def loop_sum(n):
      s = 0
      for i in range(1, n + 1): s += i
      return s                                      # O(n) time, O(1) space


 def formula_sum(n):
      return n * (n + 1) // 2                       # O(1)


 def rec_sum(n):
      return 0 if n == 0 else n + rec_sum(n - 1)                 # O(n) time, O(n) stack



Code Problem 4 (Medium): Is it a power of two?
Statement: Return True if n is a power of two, in O(1).
Solution:


 def is_pow2(n):
      return n > 0 and (n & (n - 1)) == 0


Explanation: a power of two has exactly one set bit; n & (n-1) clears the lowest set bit.

3.1 Linear array
A list of n items of the same type, stored in consecutive memory locations, accessed by
an index (subscript).


 Index :      0      1        2         3      4
            ┌─────┬─────┬─────┬─────┬─────┐
   DATA     │ 12   │ 45   │       7   │ 33   │ 90     │
             └─────┴─────┴─────┴─────┴─────┘
  Address: 1000         1004    1008   1012       1016     (4 bytes per int)


Terms (Lipschutz): LB (lower bound), UB (upper bound), length = UB − LB + 1.


3.2 Address calculation

  LOC(DATA[K]) = Base(DATA) + w × (K − LB)


where w = size of one element. Example: Base = 1000, w = 4, LB = 0, K = 3 → 1000 + 4×3 =
1012.
This formula is why access by index is O(1).


3.3 Operations and costs
Traversal. Visit every element: O(n).

Insertion (Algorithm 3.1: insert ITEM at position K in LA with N elements)

  1. Set J := N.
  2. Repeat Steps 3 and 4 while J >= K:
  3.        Set LA[J+1] := LA[J].                   (move element down)
  4.        Set J := J - 1.
  5. Set LA[K] := ITEM.
  6. Set N := N + 1.
  7. Exit.



  Insert 20 at index 2 :
  before: [12][45][ 7][33][90][               ]
  shift :     12   45     ─►7    ─►33 ─►90                (move right, last to first)
  after : [12][45][20][ 7][33][90]


Deletion is the reverse: shift left, O(n).


  def insert(a, k, item):                         # a is a Python list used as a fixed array
        a.append(None)
        for j in range(len(a) - 1, k, -1):
             a[j] = a[j - 1]
        a[k] = item


  def delete(a, k):
        for j in range(k, len(a) - 1):
               a[j] = a[j + 1]
        a.pop()



  Operation                                     Best         Worst

  Access by index                               O(1)         O(1)

  Search (unsorted)                             O(1)         O(n)

  Insert at end                                 O(1)         O(1) (if space)

  Insert at middle or front                     O(1)         O(n)

  Delete                                        O(1)         O(n)



3.4 Two-dimensional arrays
A table with rows and columns: A[i][j] .


               col0       col1       col2
 row0      [    1     |    2     |    3     ]
 row1      [    4     |    5     |    6     ]
 row2      [    7     |    8     |    9     ]


Row-major order (C, Python, Java): row 0, then row 1, ...
LOC(A[i][j]) = Base + w × (i × COLS + j)
Column-major order (Fortran): column 0, then column 1, ...
LOC(A[i][j]) = Base + w × (j × ROWS + i)

Example: 3×3, Base = 2000, w = 2, row-major, A[2][1] → 2000 + 2×(2×3+1) = 2014.


3.5 Records
A record groups fields of different types.

 class Student:
        def __init__(self, roll, name, marks):
               self.roll, self.name, self.marks = roll, name, marks


 students = [Student(101, "Zara", 88), Student(102, "Arun", 75)]          # array of records
3.6 Pointers (idea)
A pointer stores the address of another variable. Pointers make linked structures possible
(Module 7).


   p ─────────►    [ 42 ]
 (address 3000)     value at 3000




3.7 Common array patterns (beginner toolkit)
   Prefix sums: pre[i] = pre[i-1] + a[i] , so any range sum is pre[r] - pre[l-1] in
   O(1).
   Reverse in place: swap a[i] and a[n-1-i] .
   Rotate: reverse the whole array, then reverse the two parts.
   Kadane-style max subarray (preview for Course 2).


Common mistakes
   Off-by-one errors (index runs 0..n−1).
   Shifting in the wrong direction when inserting (overwrites data).
   Assuming a Python list is a fixed array. It is a dynamic array.


Quick revision
Arrays give O(1) index access thanks to the address formula. Insert and delete in the middle
cost O(n) because of shifting. A 2D array is stored row by row (row-major).

Code Problem 1 (Easy): Reverse an array in place
Example: [1,2,3,4,5] → [5,4,3,2,1]


 def reverse(a):
      i, j = 0, len(a) - 1
      while i < j:
           a[i], a[j] = a[j], a[i]
           i += 1; j -= 1
      return a


Complexity: O(n) time, O(1) space.


Code Problem 2 (Easy): Second largest element
Statement: Find the second largest distinct value in one pass.
Example: [12, 35, 1, 10, 34, 1] → 34
 def second_largest(a):
      first = second = float('-inf')
      for x in a:
           if x > first:
                 first, second = x, first
           elif first > x > second:
                 second = x
      return second if second != float('-inf') else None


Complexity: O(n), O(1).

5.1 Definition
A function is recursive if it calls itself with a smaller input. Every recursive solution needs:

1. Base case: a stopping condition with a direct answer.
2. Recursive case: moves toward the base case.


5.2 Factorial
n! = n × (n−1)!, with 0! = 1.


  def fact(n):
       if n == 0:               # base case
             return 1
       return n * fact(n - 1)        # recursive case


Call stack trace of fact(4)


  fact(4) → 4 * fact(3)
                    fact(3) → 3 * fact(2)
                                    fact(2) → 2 * fact(1)
                                                    fact(1) → 1 * fact(0)
                                                                    fact(0) → 1
  unwinding:     fact(1)=1 · fact(2)=2 · fact(3)=6 · fact(4)=24



  Call stack (top ↑)
   ┌─────────┐
   │ fact(0) │ ← top
   │ fact(1) │
   │ fact(2) │
   │ fact(3) │
   │ fact(4) │ ← bottom (first call)
   └─────────┘


Time O(n), space O(n) (stack depth).
5.3 Fibonacci
F(0)=0, F(1)=1, F(n)=F(n−1)+F(n−2).


 def fib(n):
        if n < 2: return n
        return fib(n-1) + fib(n-2)


Recursion tree for fib(5)


                            fib(5)
                        /            \
                   fib(4)            fib(3)

 def fib(n):
        if n < 2: return n
        if n not in memo:
              memo[n] = fib(n-1) + fib(n-2)
        return memo[n]                      # now O(n)




5.4 Tower of Hanoi [L]
Move n disks from peg A to peg C using peg B; never place a larger disk on a smaller one.


 Procedure: Hanoi(n, A, C, B)
 1. If n = 1: move disk from A to C. Return.
 2. Hanoi(n-1, A, B, C)                          (move n-1 disks out of the way)
 3. Move disk n from A to C.
 4. Hanoi(n-1, B, C, A)                          (put them on top)


Moves required: 2ⁿ − 1. Time O(2ⁿ).


 n=2:        A: [1,2]        B: []        C: []
   move 1: A→B              A:[2]        B:[1]
   move 2: A→C       A:[]       B:[1]   C:[2]
   move 3: B→C       A:[]       B:[]    C:[1,2]




5.5 Other classic recursions
   Power: pow(x, n) = x * pow(x, n-1) is O(n); the smarter pow(x, n) = pow(x, n/2)²
   is O(log n).
   GCD (Euclid): gcd(a, b) = gcd(b, a mod b) , with base gcd(a, 0) = a .
   Sum of digits, reverse a string, binary search (recursive).


5.6 Recursion vs iteration

                    Recursion                                      Iteration

  Code              short, elegant                                 longer

  Space             O(depth) stack                                 O(1) usually

  Risk              stack overflow                                 none

  Best for          trees, divide and conquer                      simple repetition


Any recursion can be converted to a loop with an explicit stack.


Common mistakes
   Missing or wrong base case (infinite recursion).
   Recursive call not moving closer to the base case.
   Using naïve Fibonacci for large n.


Quick revision
Base case plus recursive case. Calls pile up on the stack. Overlapping sub-problems mean
you should memoize.

 Algorithm 6.1 (Binary search) [L]
 1. Set BEG := LB, END := UB, MID := INT((BEG+END)/2).
 2. Repeat Steps 3 and 4 while BEG <= END and DATA[MID] != ITEM:
 3.      If ITEM < DATA[MID], set END := MID - 1.
         Else set BEG := MID + 1.

6.4 Bubble sort
Repeatedly swap adjacent out-of-order pairs. After pass k, the k largest items are in place.


 [5, 1, 4, 2]
 pass1: 1 5 4 2 → 1 4 5 2 → 1 4 2 5
 pass2: 1 4 2 5 → 1 2 4 5
 pass3: no swaps → sorted



 def bubble(a):
      n = len(a)
      for p in range(n - 1):
          swapped = False
          for i in range(n - 1 - p):
                if a[i] > a[i+1]:
                    a[i], a[i+1] = a[i+1], a[i]
                    swapped = True
          if not swapped: break          # best case O(n)




6.5 Selection sort
Find the minimum of the unsorted part and swap it to the front.
  [29, 10, 14, 37, 13]
   pick 10 → [10, 29, 14, 37, 13]
   pick 13 → [10, 13, 14, 37, 29]
   pick 14 → already placed
   pick 29 → [10, 13, 14, 29, 37]


Always O(n²) comparisons, but only n−1 swaps.


6.6 Insertion sort
Build a sorted prefix; insert each new item into its place (like sorting playing cards).


  [7, 3, 5, 1]
   take 3 : [3, 7, 5, 1]
   take 5 : [3, 5, 7, 1]
   take 1 : [1, 3, 5, 7]



  def insertion(a):
      for i in range(1, len(a)):
              key, j = a[i], i - 1
              while j >= 0 and a[j] > key:
                  a[j+1] = a[j]; j -= 1
              a[j+1] = key


Best case O(n) (already sorted), good for small or nearly sorted data.

7.1 Why linked lists?
Arrays need contiguous memory and O(n) shifting for insertion. A linked list stores each
element in a separate node that holds data and a pointer to the next node.


  head

  └──────┴───┘      └──────┴───┘     └──────┴───┘

             self.data = data
             self.next = None

 Delete node after p:          p → [P] → [X] → [Q]

 def delete_value(head, val):
      if head is None: return None
      if head.data == val: return head.next
      cur = head
      while cur.next and cur.next.data != val:
           cur = cur.next
      if cur.next:
           cur.next = cur.next.next
      return head

 def to_postfix(s):
     prec = {'+': 1, '-': 1, '*': 2, '/': 2, '^': 3}
     out, st = [], []
     for ch in s:
         if ch.isalnum(): out.append(ch)
         elif ch == '(': st.append(ch)
         elif ch == ')':
               while st and st[-1] != '(': out.append(st.pop())
               st.pop()
         else:
               while st and st[-1] != '(' and (prec[st[-1]] > prec[ch] or
                      (prec[st[-1]] == prec[ch] and ch != '^')):
                    out.append(st.pop())
               st.append(ch)
     while st: out.append(st.pop())
     return ''.join(out)


Complexity: O(n).

9.3 Circular queue
Wrap the indices using modulo, so the array is treated as a ring.


               index 0
           ┌───┐
     4 ───┤      ├─── 1
           │     │
     3 ───┤      ├─── 2
           └───┘
   rear = (rear + 1) % N
   front = (front + 1) % N



 class CircularQueue:
      def __init__(self, n):
           self.a = [None]*n; self.n = n
           self.front = 0; self.size = 0
      def enqueue(self, x):
           if self.size == self.n: raise OverflowError
           self.a[(self.front + self.size) % self.n] = x
           self.size += 1
      def dequeue(self):
           if self.size == 0: raise IndexError
           x = self.a[self.front]
           self.front = (self.front + 1) % self.n
           self.size -= 1
           return x


Tracking size separates "full" from "empty" (both can have front == rear otherwise).

Keep front and rear pointers: enqueue at the rear, dequeue at the front, both O(1).

2. One child: replace the node with its child.
3. Two children: replace its value with its in-order successor (smallest in the right
   subtree), then delete that successor.

 def insert(r, k):
      if r is None: return TreeNode(k)
      if k < r.val: r.left = insert(r.left, k)
      elif k > r.val: r.right = insert(r.right, k)
      return r


 def delete(r, k):
      if r is None: return None
      if k < r.val: r.left = delete(r.left, k)
      elif k > r.val: r.right = delete(r.right, k)
      else:
          if not r.left: return r.right
          if not r.right: return r.left
          succ = r.right
          while succ.left: succ = succ.left
          r.val = succ.val
          r.right = delete(r.right, succ.val)
      return r


Complexity: O(h), where h is the height.

         st, cur = [], r
         while True:
             while cur: st.append(cur); cur = cur.left
             cur = st.pop(); k -= 1
             if k == 0: return cur.val
             cur = cur.right


Complexity: O(h + k).

11.3 Breadth-First Search (BFS)
Explore level by level using a queue.


 from collections import deque
 def bfs(adj, start):
        seen = {start}; q = deque([start]); order = []
        while q:
            u = q.popleft(); order.append(u)
            for v in adj[u]:
                 if v not in seen:
                       seen.add(v); q.append(v)
      return order



 Graph:      0 ── 1 ── 3
             │     │
             2 ── 4
 BFS from 0:      level0: 0 | level1: 1, 2 | level2: 3, 4         → order 0 1 2 3 4


Time O(V + E). In an unweighted graph, BFS finds the shortest path (fewest edges).


11.4 Depth-First Search (DFS)
Go as deep as possible, then backtrack, using recursion or a stack.

 def dfs(adj, u, seen):
      seen.add(u)
      for v in adj[u]:
            if v not in seen:
                 dfs(adj, v, seen)



 DFS from 0 on the graph above (neighbours in ascending order):
  0 → 1 → 3 (dead end, back) → 4 → 2 → done              order: 0 1 3 4 2


Time O(V + E).

Code Problem 3 (Medium): Number of islands
Statement: In a grid of '1' (land) and '0' (water), count islands (4-direction connectivity).


 def num_islands(g):
      if not g: return 0
      R, C, count = len(g), len(g[0]), 0
      def sink(r, c):
           if r < 0 or c < 0 or r >= R or c >= C or g[r][c] != '1': return
           g[r][c] = '0'
           sink(r+1, c); sink(r-1, c); sink(r, c+1); sink(r, c-1)
      for r in range(R):
           for c in range(C):
                 if g[r][c] == '1':
                     count += 1; sink(r, c)
      return count


Complexity: O(R·C).


Code Problem 4 (Medium): Shortest path in a maze (BFS)
Statement: Grid with 0 (open) and 1 (wall); find the fewest steps from (0,0) to (R−1,C−1), or
−1.


 from collections import deque
 def shortest(grid):
      R, C = len(grid), len(grid[0])
      if grid[0][0] or grid[R-1][C-1]: return -1
      q, seen = deque([(0, 0, 0)]), {(0, 0)}
      while q:
           r, c, d = q.popleft()
           if (r, c) == (R-1, C-1): return d
           for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
                 nr, nc = r + dr, c + dc
                 if 0 <= nr < R and 0 <= nc < C and not grid[nr][nc] and (nr, nc) not in seen:
                     seen.add((nr, nc)); q.append((nr, nc, d + 1))
      return -1
Code Problem 5 (Medium): Detect a cycle in an undirected graph

 def has_cycle(n, adj):
      seen = set()
      def dfs(u, parent):
           seen.add(u)
           for v in adj[u]:
               if v not in seen:
                     if dfs(v, u): return True
               elif v != parent:
                     return True
           return False
      return any(dfs(s, -1) for s in range(n) if s not in seen)

12.1 Hashing
A hash function h(key) maps a key to an index of a table of size m.


  key "Zara" ──► h("Zara") = 17 mod 10 = 7
  table:    0 1 2 3 4 5 6 [7: Zara] 8 9


Goals: fast to compute, spreads keys uniformly.
Common hash functions [L]

   Division: h(k) = k mod m (choose m prime).
   Mid-square: square the key, take the middle digits.
   Folding: split the key into parts and add them.
   Strings: h(s) = (s[0]·p⁰ + s[1]·p¹ + ...) mod m .


12.2 Collisions
Two different keys give the same index (inevitable, since there are more keys than slots).
Chaining: each slot holds a linked list.


   0: ∅
   1: [11] → [21] → ∅
   2: [12] → ∅
   3: ∅


Open addressing (linear probing): if slot taken, try the next one.

 insert 11 (h=1) → slot 1
 insert 21 (h=1) → taken → slot 2
 insert 31 (h=1) → taken, taken → slot 3


Load factor α = n / m. Keep α below about 0.7, otherwise resize and rehash.


12.3 Cost

  Operation                                          Average         Worst (all collide)

  insert                                             O(1)            O(n)

  search                                             O(1)            O(n)

  delete                                             O(1)            O(n)

  Hash tables do not keep keys ordered.

Code Problem 5 (Medium): Hash table with chaining

 class HashTable:
      def __init__(self, m=8):
          self.m, self.n = m, 0
          self.t = [[] for _ in range(m)]
      def _idx(self, k): return hash(k) % self.m
      def put(self, k, v):
          b = self.t[self._idx(k)]
          for i, (kk, _) in enumerate(b):
               if kk == k: b[i] = (k, v); return
          b.append((k, v)); self.n += 1
          if self.n / self.m > 0.75: self._grow()
      def get(self, k):
          for kk, v in self.t[self._idx(k)]:
                if kk == k: return v
            return None
        def _grow(self):
            old = [kv for b in self.t for kv in b]
            self.m *= 2; self.n = 0
            self.t = [[] for _ in range(self.m)]
            for k, v in old: self.put(k, v)


Complexity: O(1) average for put/get; growing is amortised O(1).
